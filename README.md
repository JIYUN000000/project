- **특징:**  
  - `game_data.py`에서 제공하는 데이터에서 무작위로 두 계정을 선택하여 비교  
  - 사용자가 더 많은 팔로워를 가진 계정을 맞히면 점수가 올라가며 게임이 계속 진행됨  
  - 오답을 입력하면 게임 종료 및 최종 점수 출력  

- **게임 흐름:**

  4. **사용자 입력:** `A` 또는 `B` 입력  
  5. **정답 확인:**  
     - 맞히면 `점수 +1` 및 새로운 비교 대상 생성  
     - 틀리면 게임 종료 후 최종 점수 출력  

- **사용 기술:**  
  Python, 리스트, 딕셔너리, 조건문, 반복문, 랜덤 모듈

- **개선 방향**  
1. **함수 활용 최적화:**  
   - `check_answer()` 함수가 존재하지 않으므로, 솔루션 코드처럼 별도 함수로 분리하면 유지보수에 용이함.  

2. **사용자 경험 개선:**  
   - `print("\n"*20)`과 같이 화면을 지우는 기능을 추가하면, 게임 진행 중 이전 라운드의 정보가 사라져 더 깔끔한 UI를 제공할 수 있음.  

3. **정답 확인 과정 단순화:**  
   - `check_answer()` 함수에서 `if a_followers > b_followers:`와 같이 조건을 단순하게 비교하면 코드가 더 간결해짐.
  
## 1️⃣5️⃣ ☕ 커피 머신 프로그램

  - 메뉴에 따라 필요한 **재료(물, 우유, 커피)**를 확인하여 충분한지 체크  
  - 사용자에게 동전을 입력받아 결제(쿼터, 다임, 니켈, 페니 지원)

  - **"off"** 입력 시 프로그램 종료

  3. **결제 진행:** 동전 입력 후 금액 비교  
  4. **커피 제조:** 성공 시 자원 차감 후 제공, 부족하면 오류 메시지 출력  
  5. **반복 실행:** 사용자가 "off" 입력 시까지 계속 주문 가능  

- **개선 방향**
1. **자원 및 수익 관리 추가**  
   - 솔루션 코드처럼 `profit` 변수를 사용하여 **총 수익**을 추적하는 기능을 추가하면 현실적인 시뮬레이션이 가능함.  

2. **반복 구조 최적화**  
   - `while is_on:`과 같이 `True` 값을 가진 변수를 이용하면 **반복 실행 구조가 더 명확해짐**.  

3. **함수 역할 명확화**  
   - `is_transaction_successful()`과 같은 함수를 활용하면 **잔돈 계산 및 결제 결과 관리**가 더 깔끔해짐.  

4. **사용자 경험 개선**  
   - 사용자가 **잘못된 입력**을 했을 때 `"Invalid input"` 메시지를 추가하여 안내 기능을 강화할 수 있음.
