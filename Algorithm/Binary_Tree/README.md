**Binary Tree**

    - **모든 노드가 최대 2개의 자식 노드(왼쪽, 오른쪽)**를 가지는 계층적 자료구조다.
      각 노드는 데이터와 **왼쪽/오른쪽 자식 노드에 대한 참조(포인터)**를 가진다.

**트리 구성 방법**
    
    - 파이썬에서는 클래스를 활용해 이진 트리를 구성할 수 있다.
      
    - data: 노드가 담고 있는 값
    
    - leftChild: 왼쪽 자식 노드를 가리킴
    
    - rightChild: 오른쪽 자식 노드를 가리킴

**트리 순회 방법**

    - 트리 순회(Tree Traversal)란, 트리의 각 노드를 특정한 순서로 한 번씩 방문하는 방법이다.
      대표적으로 전위 (루트 => 왼쪽 => 오른쪽), 중위 (왼쪽 => 루트 => 오른쪽), 후위 (왼쪽 => 오른쪽 => 루트) 3가지 순회 방식이 있다.

**시간 복잡도**

    - O(N), 여기서 N은 트리의 노드 수를 의미한다.
    
    - 모든 노드를 각 한 번씩 방문하며, 각 노드에서 **고정된 작업(프린트, 재귀 호출)**만 수행하므로, 총 연산량은 노드 수에 비례한다.

**공간 복잡도**
    
    - 최악의 경우 (편향 트리): 재귀 호출 스택 깊이 = O(N)
    
    - 완전 이진 트리의 경우: 트리 높이 = O(log N), 따라서 공간 복잡도도 O(log N)
