**Union Find 알고리즘**

    - Union-Find는 서로소 집합(Disjoint Set) 자료구조를 이용하여 두 집합을 합치고 두 원소가 같은 집합에 속하는지 확인하는 알고리즘이다.
      이 알고리즘은 집합 합치기(Union)와 집합 찾기(Find) 연산을 효율적으로 처리하기 위해 사용된다. 
      주로 그래프에서의 연결 요소 탐색이나 최소 스패닝 트리(MST)를 찾는 알고리즘에 사용된다.

**Union Find 핵심 연산**

    - Find
      : 두 노드가 같은 집합에 속하는지 확인하는 연산이다. 
      각 노드는 부모 노드를 참조하는데, 이 부모 노드를 따라가며 루트 노드를 찾는다. 
      두 노드의 루트 노드가 같으면 같은 집합에 속한다.
  
    - Union
      : 두 집합을 합치는 연산이다. 두 집합을 합칠 때, 각 집합의 루트 노드를 찾은 후 두 집합을 합친다. 
      일반적으로 두 집합 중 작은 트리를 큰 트리 밑에 합치는 방식(Union by Rank)을 사용하여 트리의 높이를 최소화한다.

**Union-Find의 최적화 기법**

    1. 경로 압축 (Path Compression):
    
    - find 연산을 수행할 때 경로 압축을 통해 탐색 경로를 최적화한다. 
    경로 압축은 find 연산 중에 방문한 모든 노드가 직접 루트를 가리키게 하여, 향후 탐색 속도를 빠르게 만든다. 
    이 기법을 통해 시간 복잡도를 개선할 수 있다.
    
    2. Union by Rank:
    
    - union 연산에서 두 트리의 높이를 비교하여 더 작은 트리를 더 큰 트리 아래에 결합하는 방식이다. 
    이 기법을 통해 트리의 깊이를 최소화하고, 탐색 속도를 최적화한다.

**Union-Find의 시간 복잡도**

    - find 연산과 union 연산의 시간 복잡도는 경로 압축과 Union by Rank 기법을 사용할 경우, **O(α(N))**로 매우 빠르다. 
    여기서 **α(N)**는 아커만 함수의 역함수로, 실제로는 상수 시간에 가까운 속도로 동작한다.
