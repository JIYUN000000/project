**Dynamic Programming**

  - 복잡한 문제를 작은 문제로 나누어 해결하고, 한 번 계산한 결과를 저장하여 다시 계산하지 않도록 최적화하는 알고리즘 설계 기법이다.

**핵심 개념**

  - 작은 문제로 나누기 (Divide)
  
    - 큰 문제를 같은 형태의 더 작은 문제로 나눈다.
  
  - 부분 문제의 정답 재사용 (Memoization / Tabulation)
  
    - 이미 계산한 결과를 배열 등에 저장해 재사용함으로써 중복 계산을 피한다.
  
  - 최적 부분 구조 (Optimal Substructure)
  
    - 문제의 정답이 작은 부분 문제의 정답으로 구성될 수 있어야 한다.
   
**구현 방식**

  - Top-Down (재귀 + 메모이제이션)
  
      - 큰 문제를 해결하기 위해 작은 문제를 재귀 호출하며 내려가고, 이미 계산한 결과는 저장 (fibonacci(n)을 재귀로 구현하면서, 계산 결과를 배열에 저장)
  
  - Bottom-Up (반복문 + 테이블)
  
    - 작은 문제부터 차례로 계산하여 큰 문제로 확장 (피보나치 수를 배열의 처음부터 쌓아가는 방식)
 
**DP를 사용할 수 있는 조건**

  - 중복되는 부분 문제 (Overlapping Subproblems): 동일한 계산을 반복하는 경우
  
  - 최적 부분 구조 (Optimal Substructure): 전체 문제의 최적해가 부분 문제의 최적해로 구성될 수 있는 경우

**시간 복잡도**

  - 해당 코드의 경우 시간 복잡도는 O(N)
