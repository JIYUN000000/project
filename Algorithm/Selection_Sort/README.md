** 선택 정렬 (Selection Sort)
: 선택 정렬은 가장 작은 값을 선택해서 앞쪽부터 차례대로 정렬하는 알고리즘이다. 매 반복마다 가장 작은 값을 찾아 맨 앞의 값과 교환한다.

** 알고리즘 성능 분석
총 비교 횟수: 10 + 9 + 8 + ... + 1 = 55
수식: N * (N + 1) / 2

** 시간 복잡도:
- 모두 O(N²)
- 데이터가 많아지면 비효율적

** 한계:
- 구현은 간단하지만, 효율적인 정렬이 아님

** 파이썬과 C 문법 비교
| 개념            | 파이썬                        | C 언어                                |
|----------------|-------------------------------|----------------------------------------|
| 배열 선언       | `arr = [1, 2, 3]`              | `int arr[3] = {1, 2, 3};`              |
| 반복문 (for)    | `for i in range(10):`         | `for(i = 0; i < 10; i++)`              |
| 출력            | `print(x)`                    | `printf("%d", x);`                     |
| 변수 선언       | 자동                           | `int x = 10;` (자료형 명시 필요)      |
| 들여쓰기        | 문법적으로 중요               | `{}` 중괄호로 구역 표시               |
| 배열 접근       | `arr[i]`                       | `arr[i]` (동일)                        |
