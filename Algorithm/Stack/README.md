**Stack**
        
        - 후입선출(Last In First Out, LIFO) 방식으로 데이터를 저장하는 자료구조. 즉, 나중에 들어간 데이터가 먼저 나온다.
          
        - 재귀, 괄호 매칭, 깊이 우선 탐색(DFS) 등 다양한 알고리즘에 사용된다.

**Stack의 주요 연산**

        - push: 스택의 맨 위에 데이터를 넣기
        
        - pop: 스택의 맨 위에서 데이터를 빼기
          
        - top: 스택의 맨 위에 있는 데이터를 조회
          
        - empty: 스택이 비어있는지 확인
          
        - size: 스택에 저장된 데이터의 갯수를 확인

**시간 복잡도**

        - push(), pop(), top(), empty() 모두 O(1)로 일정하다.
