**에라토스테네스의 체**

    - 2부터 시작하여 소수가 아닌 수를 지워 나가는 방식으로 소수를 빠르게 구하는 알고리즘이다.
      1부터 N까지의 자연수 중에서 소수만 걸러내는 데 매우 효율적이다.

**알고리즘 개념**

    - 2부터 N까지 모든 수를 나열한다.
    
    - 현재 남아있는 수 중에서 가장 작은 수를 소수로 기록한다.
    
    - 그 수의 배수(소수가 아닌 것)를 모두 지운다. 
    
    - 위 과정을 남아있는 수가 없을 때까지 반복한다.
    
    - 지워지지 않고 남은 수들이 소수다.

**시간 복잡도**

    - O(N log log N)
    
    - log log N인 이유:
    
      - 각 소수 i 에 대해 그 배수들을 지우는 연산은 n/i번 발생한다.
     
      - 이때 i는 소수이므로, 모든 소수에 대해 합하면 N(1/2 + 1/3 + 1/5 + 1/7 + ... ), 이 합은 수학적으로 log log N에 수렴한다.
