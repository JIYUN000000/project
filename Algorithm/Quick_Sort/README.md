** Quick Sort: 퀵 정렬은 분할 정복(Divide and Conquer) 방식으로 배열을 반복적으로 나누어서 정렬하는 효율적인 알고리즘이다.

** 알고리즘 설명
1. 피벗 선택: 배열의 첫 번째 원소를 피벗으로 선택한다.
2. 분할 과정:
- 배열을 피벗을 기준으로 두 부분으로 나눈다.
- 왼쪽 부분은 피벗보다 작은 값들, 오른쪽 부분은 피벗보다 큰 값들로 배치된다.
3. 재귀 호출: 피벗을 기준으로 나누어진 두 부분에 대해 퀵 정렬을 재귀적으로 수행한다.
4. 배열의 크기가 1 이하가 될 때까지 이 과정을 반복한다.

** 코드 설명
- quickSort 함수는 start와 end 인덱스를 이용해서 배열의 부분 범위에 대해 정렬을 수행한다.
- 피벗은 배열의 첫 번째 원소로 설정하고, 두 개의 인덱스 i와 j를 이용해서 배열을 두 부분으로 나눈다.
- i는 피벗보다 큰 값을 찾고, j는 피벗보다 작은 값을 찾는다.
- i와 j가 엇갈리면 피벗을 j 위치의 값과 교환해서 피벗을 정렬된 위치로 이동시킨다.
- 두 부분 배열에 대해 재귀적으로 정렬을 계속 수행한다.
