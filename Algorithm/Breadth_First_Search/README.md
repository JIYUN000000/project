**Breadth-First Search**
    
    - 그래프나 트리의 탐색 알고리즘 중 하나로, 시작 노드에서부터 인접한 노드들을 먼저 탐색하고, 그 후 그 노드들의 인접 노드들을 차례대로 탐색하는 방식.
      탐색 순서가 층층이 확장되는 특징을 가진다.
      
    - Queue 자료구조를 사용하여, 먼저 들어온 노드를 먼저 처리하는 FIFO(First In, First Out) 방식으로 탐색을 수행한다.

**BFS의 동작 원리**

    1. 시작 노드에서 탐색을 시작한다.
    
    2. 시작 노드를 큐에 넣고 방문 처리한다.
    
    3. 큐에서 노드를 하나씩 꺼내면서, 그와 연결된 인접 노드들을 큐에 넣고 방문 처리한다.
    
    4. 큐가 비어있을 때까지 이 과정을 반복한다.
    
    5. BFS는 층(layer)별로 탐색을 진행하므로, 먼저 방문한 노드부터 차례대로 탐색된다.

**BFS의 시간 복잡도**

    - O(V + E), 여기서 V는 정점의 수(노드의 수), E는 간선의 수(노드들 간의 연결)를 나타낸다.
    
    - BFS는 모든 노드와 모든 간선을 한 번씩만 처리하므로 노드와 간선의 수에 비례하여 탐색이 이루어진다.
