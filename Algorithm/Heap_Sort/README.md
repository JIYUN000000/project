**Heap Sort**

    - 힙 자료구조를 이용하여 배열을 정렬하는 알고리즘. 힙은 이진 트리 형태의 자료구조로, Max Heap과 Min Heap이 있다.
      
    - 힙 정렬은 최대 힙을 사용하여 내림차순 정렬을 수행한 후, 가장 큰 값을 배열의 끝으로 보내며 오름차순 정렬을 완성한다.

** 시간 복잡도
  
    - 최대 힙 만들기: 최대 힙을 만들기 위해 **heapify**를 n / 2번 호출하고, 각 호출에서 O(log n) 시간이 걸린다. 따라서 최대 힙을 만드는 시간 복잡도는 **O(n)**이다.
    
    - 정렬: 배열의 각 원소에 대해 **heapify**를 호출하며, 각 호출에서 O(log n) 시간이 걸린다. 따라서 정렬의 시간 복잡도는 **O(n log n)**입니다.
    
    - 전체 시간 복잡도: 힙 정렬의 전체 시간 복잡도는 **O(n log n)**이다.
