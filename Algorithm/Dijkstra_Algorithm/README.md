**다익스트라 알고리즘(Dijkstra's Algorithm)**

    - 하나의 시작 정점에서 모든 다른 정점까지의 최단 경로를 구하는 알고리즘이다.
      간선의 가중치가 모두 양수일 때 사용 가능하다.
    
    - 그 이전까지 구한 최단 거리를 바탕으로 다음 노드의 최단 거리를 계산한다.
    
    - 이미 확정된 최단 거리는 변하지 않으므로, 새로운 최단 거리 계산 시 항상 신뢰할 수 있는 기준이 된다.
    
    - 이러한 방식으로 불필요한 재계산을 피하고, 최적의 경로를 빠르게 찾을 수 있다.

**알고리즘 개념**

    - 최단 거리 테이블을 사용하여 각 정점까지의 최단 거리 정보를 지속적으로 갱신한다.
    
    - 시작 정점에서 가장 가까운 노드부터 차례대로 방문하면서, 이미 구한 최단 거리 정보를 기반으로 새로운 노드의 최단 거리를 계산한다.
    
    - 이전까지 구한 최단 거리를 그대로 사용하여, 이후 노드들의 거리 계산을 더 빠르고 정확하게 수행할 수 있다.

**알고리즘 동작 방식**

    1. 모든 노드의 최단 거리 값을 무한대(INF)로 초기화한다.
    
    2. 시작 노드의 최단 거리는 0으로 설정한다.
    
    3. 아직 방문하지 않은 노드 중에서 가장 최단 거리가 짧은 노드를 선택한다.
    
    4. 해당 노드를 거쳐 갈 수 있는 인접 노드들의 최단 거리를 계산하고, 더 짧은 경로가 발견되면 최단 거리 테이블을 갱신한다.
    
    5. 모든 노드를 방문할 때 까지 3~4번 과정을 반복한다.
