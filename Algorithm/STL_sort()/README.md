**sort 함수**

    - 배열 또는 벡터 등의 요소를 정렬하는 함수로, 기본적으로 오름차순으로 정렬되며 정렬 기준을 커스터마이즈 할 수 있다. 
    
    - C++의 <algorithm> 라이브러리에 포함되어 있으며, 효율적인 정렬 알고리즘을 사용한다.

** 사용법

    - 형태: sort(배열의 첫 요소, 배열의 끝 요소);
    
    - 매개 변수 (첫 번째 인자: 정렬할 배열의 첫 번째 요소를 가리키는 포인터, 두 번째 인자: 정렬할 배열의 끝 요소를 가리키는 포인터 - 배열 + 크기 - )

** 동작 원리
    - 두 원소를 비교하여 순서를 바꾸는 방식으로 배열을 정렬한다.
    
    - 내부적으로 퀵 정렬, 병합 정렬 또는 힙 정렬과 같은 알고리즘을 사용하여 효율적인 시간 복잡도를 보장한다.
    
    - 정렬 기준 커스터마이징을 위해 비교 연산자(operator) 를 오버로딩 하거나 람다 함수를 사용할 수 있음

** 시간 복잡도
    - 평균적인 시간 복잡도: O(n log n).
    
    - 최악의 경우에도 **O(n log n)**로 동작한다. (퀵 정렬을 사용한 경우 최악의 경우에도 O(n log n)을 보장하는 최적화된 퀵 정렬 알고리즘이 사용된다.)
   
    
**자료구조**

** vector
   
   - vector는 동적 배열을 제공하는 C++ STL(Standard Template Library)의 컨테이너. 크기가 고정된 배열과 달리, 동적으로 크기를 변경할 수 있어 매우 유용하다.

   - vector는 원소를 추가할 때마다 자동으로 크기를 조정하고, 배열처럼 인덱스를 통해 원송 O(1) 시간에 접근할 수 있다.

   - 내부적으로 동적 메모리를 사용하여, 크기가 변경될 때마다 자동으로 메모리를 재배치한다.

   - 주요 연산
    push_back(): 벡터의 끝에 원소를 추가

    pop_back(): 벡터의 마지막 원소를 제거
    
    size(): 벡터의 크기를 반환
    
    begin(): 벡터의 첫 번째 원소를 가리키는 이터레이터를 반환
    
    end(): 벡터의 마지막 원소의 뒤를 가리키는 이터레이터를 반환

** pair
    - 두 값을 묶어서 하나의 객체로 저장할 수 있는 C++ STL의 자료형. 각 pair 객체는 두 개의 값을 저장하며, **first**와 **second**라는 멤버로 접근한다.
    
    - 두 개의 서로 다른 타입을 하나의 단위로 묶을 수 있어 복합적인 데이터 구조를 만들 때 유용하다.
    
    - 다양한 자료형의 값들을 한 번에 처리할 수 있어 복잡한 데이터를 다룰 때 편리하다.
