** sort 함수
    - 배열 또는 벡터 등의 요소를 정렬하는 함수로, 기본적으로 오름차순으로 정렬되며 정렬 기준을 커스터마이즈 할 수 있다. 
    - C++의 <algorithm> 라이브러리에 포함되어 있으며, 효율적인 정렬 알고리즘을 사용한다.

** 사용법
    - 형태: sort(배열의 첫 요소, 배열의 끝 요소);
    - 매개 변수 (첫 번째 인자: 정렬할 배열의 첫 번째 요소를 가리키는 포인터, 두 번째 인자: 정렬할 배열의 끝 요소를 가리키는 포인터 - 배열 + 크기 - )

** 동작 원리
    - 두 원소를 비교하여 순서를 바꾸는 방식으로 배열을 정렬한다.
    - 내부적으로 퀵 정렬, 병합 정렬 또는 힙 정렬과 같은 알고리즘을 사용하여 효율적인 시간 복잡도를 보장한다.
    - 정렬 기준 커스터마이징을 위해 비교 연산자(operator) 를 오버로딩 하거나 람다 함수를 사용할 수 있음

** 시간 복잡도
    - 평균적인 시간 복잡도: O(n log n).
    - 최악의 경우에도 **O(n log n)**로 동작한다. (퀵 정렬을 사용한 경우 최악의 경우에도 O(n log n)을 보장하는 최적화된 퀵 정렬 알고리즘이 사용된다.)
