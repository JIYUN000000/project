** 병합 정렬 (Merge Sort) 구현
- 이 코드는 병합 정렬(Merge Sort) 알고리즘을 구현한 것이다. 병합 정렬은 분할 정복(Divide and Conquer) 방식으로 배열을 반으로 나누어 각각 정렬하고, 그 두 배열을 병합하여 정렬된 배열을 만드는 알고리즘이다.

** 알고리즘 설명
1. 배열 분할:
  - 배열을 두 개의 부분 배열로 나눈다. 배열의 크기가 1이 될 때까지 이 과정을 반복한다.
  - 중간을 기준으로 배열을 두 부분으로 나누고 재귀적으로 나눈다.

2. 병합 과정:
  - 나누어진 배열 두 개를 **병합(merge)**하여 하나의 정렬된 배열로 합친다.
  - 두 배열을 비교하면서 작은 값부터 하나씩 병합해 나간다.

3. 재귀 호출:
  - 배열이 크기가 1이 될 때까지 반복적으로 분할하고, 분할된 배열들을 병합하면서 정렬한다.

** 코드 설명
1. mergeSort 함수는 배열의 **시작 인덱스(m)**와 **끝 인덱스(n)**를 인자로 받아서 배열을 나누고 정렬한다.

2. 배열을 나누는 과정:
  - mergeSort 함수는 배열을 중간 지점(middle)을 기준으로 두 부분으로 나누고, 각 부분을 재귀적으로 정렬한다.

3. merge 함수는 두 개의 부분 배열을 병합하는 함수로, 정렬된 두 배열을 하나로 합친다.
  - 두 배열을 비교하며 작은 값을 먼저 넣고, 나머지 값을 남은 배열에서 그대로 삽입한다.
  - 병합된 값을 임시 배열인 sorted[]에 넣고, 마지막에 원래 배열에 복사한다.

4. 배열을 병합하는 과정:
  - 두 배열을 비교하여 작은 값을 먼저 삽입하고, 남은 값을 그대로 삽입한다.
  - sorted[] 배열에 병합된 값을 저장하고, 결과적으로 원본 배열에 반영한다.

5. 재귀적으로 배열을 분할하고 병합하는 과정이 배열 크기가 1이 될 때까지 반복된다.

** 시간 복잡도
  - 배열을 나누는 데 걸리는 시간: 배열의 크기가 n일 때, 배열을 나누는 횟수는 log n번이다. (log n은 분할을 몇 번 해야 하는지를 나타내는 값)
  
  - 병합하는 데 걸리는 시간: 각 병합 과정에서, 배열 크기 n에 대해 두 배열을 한 번에 병합하므로 병합에는 O(n) 시간이 소요된다.

따라서 병합 정렬의 전체 시간 복잡도는 O(n log n)이 된다. 병합을 하는 데 걸리는 시간이 전체적으로 n번의 병합 과정을 log n번 반복하는 형태이기 때문.
