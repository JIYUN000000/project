** 삽입 정렬
삽입 정렬은 데이터가 정렬되어 있다고 가정하고, 새로운 데이터를 적절한 위치에 삽입하는 방식의 정렬 알고리즘이다.
각 요소를 앞쪽으로 하나씩 비교해가며 정렬된 부분에 삽입하는 과정을 반복한다.

**장점:
- 거의 정렬된 데이터에서는 매우 빠름
- 구현이 간단하고 안정 정렬(stable sort)이다
- 실제로 사람이 카드 정렬할 때와 유사한 방식

**알고리즘 성능 분석
- 총 비교 횟수: 10 + 9 + 8 + ... + 1 = 55 (최악의 경우)
- 공식: N * (N - 1) / 2

**시간 복잡도:
- 최선 (거의 정렬된 경우): O(N)
- 평균 / 최악: O(N²)
- 공간 복잡도: O(1)

**한계:
- 데이터 양이 많고, 정렬이 안 되어 있을수록 비효율적
- 선택 정렬보다 실제 성능은 나은 편이지만, 고급 정렬 알고리즘에 비해 느림
