**Depth Fisrt Search**

    - 그래프 탐색 알고리즘 중 하나로, 시작 노드에서부터 가능한 한 방향으로 깊게 탐색하며, 더 이상 갈 곳이 없으면 다시 이전 노드로 돌아가 다른 경로를 탐색하는 방식.
      **스택(혹은 재귀 호출)**을 사용하여 깊이를 우선적으로 탐색한다.

**DFS의 동작 원리**

    1. 시작 노드에서 탐색을 시작한다.
    
    2. 현재 노드에서 인접한 노드를 하나씩 탐색하며, 더 이상 갈 곳이 없으면 이전 노드로 돌아가 다른 경로를 탐색한다.
    
    3. 탐색 순서는 시작 노드부터 깊이 우선으로 진행된다.
    
    4. 모든 노드를 탐색할 때까지 이 과정을 반복한다.

**DFS의 특징**

    - 깊이 우선 탐색: 각 노드에서 가능한 한 깊게 탐색하며, 더 이상 갈 곳이 없으면 되돌아가며 다른 경로를 탐색한다.
    
    - 스택(혹은 재귀): DFS는 스택을 사용하거나 재귀 호출을 통해 탐색을 진행한다.
    
    - 백트래킹: 깊게 탐색한 후 더 이상 갈 곳이 없으면 되돌아가 다른 경로를 탐색한다.
    
    - 방문 처리: 이미 방문한 노드는 다시 탐색하지 않도록 처리하여 무한 루프를 방지한다.

**DFS의 시간 복잡도**

    - DFS의 시간 복잡도는 **O(V + E)**이다.
      
    - V는 정점의 수(노드의 수), E는 간선의 수(노드들 간의 연결)를 나타낸다.
    
    - DFS는 모든 노드와 모든 간선을 한 번씩만 탐색하기 때문에 노드와 간선의 수에 비례한 시간 복잡도를 가진다.
