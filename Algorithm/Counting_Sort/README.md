**Counting Sort**

    - 비교 기반 정렬 알고리즘 중 하나로, 주어진 배열의 값을 빈도수로 카운트하여 정렬을 수행하는 알고리즘.
    
    - 배열의 원소가 정수일 때 매우 효율적. 성능이 일정하고 빠르며 최악의 경우에도 일정한 시간 복잡도를 가지는 알고리즘이다.

  **동작 원리**
  
    1. 주어진 배열의 각 원소가 몇 번 등장하는지 센다:

      - 배열 내의 각 원소를 카운팅 배열에 기록한다.

    2. 카운팅 배열을 기반으로 정렬된 결과 배열 만들기:

      - 빈도수 배열을 활용하여 원소를 순서대로 배치한다.


  **시간 복잡도**
      - 시간 복잡도: O(n + k)

        - n은 입력 배열의 크기이다.

        - k는 배열에 나타나는 최댓값과 최솟값 사이의 차이다. 즉, 입력 배열의 원소들이 어떤 범위에 있을 때, 그 범위(k)에 대한 의존성이 있다.

      - 공간 복잡도: O(n + k)

        - 카운팅 배열과 출력 배열을 저장하기 위한 공간이 필요하다.

      - 최악의 경우:
        - O(n + k) 이므로, 범위가 좁고 정수가 많을 때 효율적이다. 범위가 매우 크면 비효율적일 수 있다.
