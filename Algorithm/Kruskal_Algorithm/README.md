**Kruskal's Algorithm**

    - **최소 스패닝 트리(MST)**를 찾는 그리디 알고리즘이다.
      최소 스패닝 트리는 그래프에서 모든 노드를 연결하는 간선들의 부분 집합으로, 간선들의 합이 최소인 트리를 의미한다.
      크루스칼 알고리즘은 간선의 가중치가 가장 작은 간선부터 차례대로 선택하며, 사이클을 방지하는 방식으로 MST를 구성한다.

**크루스칼 알고리즘의 동작 원리**

    1. 모든 간선을 가중치 순으로 정렬한다.
    
    2. 가장 작은 가중치를 가진 간선부터 차례대로 MST에 추가한다.
    
    3. 간선을 추가할 때, 두 노드가 사이클을 형성하는지 검사한다.
    
    4. 두 노드가 같은 집합에 속하지 않으면 그 간선을 MST에 포함시킨다.
    
    5. 두 노드가 같은 집합에 속하면 사이클이 형성되므로, 그 간선은 버린다.
    
    6. 모든 노드가 연결될 때까지 이 과정을 반복한다.

**알고리즘 세부 구현**

    1. 간선 리스트를 준비한다. 각 간선은 두 노드와 간선의 가중치로 구성된다.
    
    2. 유니온-파인드(Union-Find) 자료구조를 사용하여, 두 노드가 같은 집합에 속하는지 확인하고, 두 집합을 합친다.
    
    - find: 노드가 속한 집합의 루트를 찾는다.
    
    - union: 두 노드를 합쳐 하나의 집합으로 만든다.
    
    3. 간선을 가중치 순으로 정렬하고, 간선 하나씩 선택하여 사이클을 형성하지 않으면 MST에 포함시킨다.

**시간 복잡도**
    
    - 간선 정렬: 간선이 E개일 때, **O(E log E)**의 시간이 소요된다.
    
    - 유니온-파인드 연산: find와 union은 각각 **O(α(N))**의 시간이 걸린다.
    
    - 여기서 **α(N)**는 아커만 함수의 역함수로, 매우 느리게 증가하여 실제로 상수 시간에 가까운 속도를 가진다.
