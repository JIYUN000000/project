**Queue**

    - 선입선출(First In, First Out, FIFO) 방식으로 데이터를 저장하는 자료구조. 먼저 들어온 데이터가 먼저 나오는 구조로,
      대기열처럼 먼저 온 사람이 먼저 서비스를 받는 시스템을 구현할 때 유용하다.
    -  운영체제의 프로세스 관리, 네트워크 패킷 처리, 버퍼 시스템 등에서 널리 사용된다.

**주요 연산**

    - push: 큐의 뒤에 데이터 추가.
    
    - pop: 큐의 앞에서 데이터 제거.
    
    - front: 큐의 앞에 있는 데이터 조회 (제거하지 않음).
    
    - back: 큐의 뒤에 있는 데이터 조회.
    
    - empty: 큐가 비었는지 확인.
    
    - size: 큐에 있는 데이터의 갯수를 확인.

**시간 복잡도**

    - push(), pop(), front(), empty() 모두 O(1)으로 일정하다.
